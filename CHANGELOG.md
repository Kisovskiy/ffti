# Изменения

## 1.0.0 — 24.11.2026

Первая версия.

- Разделение маршрутов: российское и игровое — напрямую, заблокированное — через туннель.
- Четыре режима: `web`, `game`, `max`, `roblox`.
- Слой обхода DPI с профилями `google`, `general`, `games`, `max`, `full`.
- Roblox: игровые серверы и CDN напрямую, веб-часть — по режиму.
- Пул прокси с выбором лучшего по замеру и обновлением из публичных списков.
- Команды: on/off/restart/status/test/doctor/refresh/mode/set/dpi/tune/config/check.
- Списки доменов и IP в текстовых файлах: правятся без кода.
- Настройки в JSON, личные правки отдельно от базовых.
- Самоподъём прав в батниках, логи по компонентам, замеры в `logs\test-*.json`.
