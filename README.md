# FFTI — Freedom For The Internet

Обход блокировок для Windows: сайты и сервисы, закрытые в России, открываются, а всё российское
идёт напрямую — без туннеля и без потери скорости. Плюс отдельный слой против DPI для того,
что режется по протоколу (YouTube, голосовой чат).

Готовые списки: Discord, Instagram, Facebook, X/Twitter, ChatGPT, Spotify, SoundCloud, Reddit,
LinkedIn, Medium, Proton, Signal, Patreon, Pixiv, TikTok, Twitch, Telegram, Netflix/HBO/Disney.
Всё остальное, включая Яндекс, ВК, банки, госуслуги, Steam и игры, — напрямую.

## Что работает

| Что | Как идёт | Проверено |
|---|---|---|
| Яндекс, ВК, Mail.ru, банки, госуслуги | напрямую, мимо туннеля | да, 300–480 мс |
| Steam, Epic, игровые серверы | напрямую | да |
| Discord (сайт, клиент) | через туннель | да, 200 |
| Instagram, X, TikTok | через туннель | да, 301/200 |
| ChatGPT | через туннель | да, 200 |
| Spotify, SoundCloud, Reddit | через туннель | да |
| Telegram | через туннель (по IP) | да |
| YouTube, Google | напрямую + DPI-слой | профиль собран из рабочих пресетов zapret; сквозная проверка — после выключения старого обхода |
| Roblox | напрямую, пинг не растёт; веб-логин — по режиму | да, 308 |

## Скачать

Готовая сборка: **[Releases → ffti-1.0.0.zip](https://github.com/Kisovskiy/ffti/releases)**

1. Распакуй архив в любую папку (например `C:\ffti`), не в `Program Files`.
2. Правый клик по `setup.ps1` → «Выполнить с помощью PowerShell» — скачает движок в `bin\`.
3. `enable.bat` — включить, `disable.bat` — выключить. Оба батника сами поднимают права.

Движок `sing-box` в архив не входит и скачивается при первом запуске — так архив остаётся
маленьким, а движок всегда свежий.

## Быстрый старт

1. `setup.ps1` — скачает `sing-box` в `bin\` и найдёт DPI-движок, если он установлен.
2. `ffti.bat refresh` — замерит пул прокси и оставит живые.
3. `ВКЛЮЧИТЬ.bat` (или `enable.bat`) — включить, `ВЫКЛЮЧИТЬ.bat` (`disable.bat`) — выключить.

После включения: `ffti.bat status` показывает режим, процессы и порты.
Локальные точки входа, если нужны вручную: HTTP `127.0.0.1:1081`, SOCKS5 `127.0.0.1:1080`.

## Режимы

| Режим | Кому | Что меняется |
|---|---|---|
| `web` | по умолчанию | заблокированное в туннель, YouTube через DPI, всё российское напрямую |
| `game` | игры | игровой трафик принудительно напрямую, DPI для голосового чата, MTU 1420 |
| `max` | «чтобы точно открылось» | широкий DPI-профиль, самый частый выбор лучшего прокси |
| `roblox` | Roblox | серверы и CDN напрямую, в туннель только веб-логин |

Переключение: `ffti.bat mode game`, затем `ffti.bat restart`.
Подробно — [docs/MODES.md](docs/MODES.md).

## Команды

| Команда | Что делает |
|---|---|
| `ffti.bat on` / `off` / `restart` | включить, выключить, перезапустить |
| `ffti.bat status` | состояние: режим, прокси, процессы, порты |
| `ffti.bat test [сайт ...]` | замер: что напрямую, что через туннель, за сколько |
| `ffti.bat doctor` | проверка окружения и типовых проблем |
| `ffti.bat refresh` | обновить и замерить пул прокси |
| `ffti.bat mode <web\|game\|max\|roblox>` | переключить режим |
| `ffti.bat set <ключ> <значение>` | изменить настройку, например `set dpi.enabled true` |
| `ffti.bat dpi on\|off\|args` | слой обхода DPI: включить, выключить, показать аргументы |
| `ffti.bat tune on\|off` | системные настройки под скорость и откат |
| `ffti.bat config` / `check` | собрать конфиг и проверить его |

## Списки

Всё лежит в `lists\` и правится блокнотом, без кода:

| Файл | Смысл |
|---|---|
| `proxies.txt` | SOCKS5-прокси пула, формат `host:port` |
| `proxy-domains.txt` | домены, которые идут через туннель (совпадение по суффиксу) |
| `proxy-ips.txt` | IP-подсети через туннель (CIDR) |
| `games-domains.txt` | игровые домены — всегда напрямую |
| `games-ips.txt` | подсети игровых серверов — всегда напрямую |
| `roblox-domains.txt` | Roblox: что уходит в туннель в режимах roblox/game |
| `proxy-sources.txt` | ссылки на публичные списки прокси для `refresh` |

Добавил домен в список — `ffti.bat config`, затем `restart`.

## Roblox и игры

Игровой трафик и CDN не заходят в туннель: пинг остаётся прежним. В режимах `roblox` и `game`
в туннель уходит только веб-часть (логин, лобби), и только если она не открывается напрямую.
Подробно — [docs/GAMES.md](docs/GAMES.md).

## Скорость

Скорость зависит от того, насколько быстрый прокси в пуле: `refresh` оставляет живые и
сортирует по замеру. Всё, что можно пустить мимо туннеля (Россия, игры, YouTube через DPI),
идёт мимо — это и есть основной выигрыш.
Замеры на реальном пуле — [docs/BENCHMARKS.md](docs/BENCHMARKS.md).

## Настройки

Все настройки — JSON в `settings\`, ключи описаны в [docs/SETTINGS.md](docs/SETTINGS.md).
Личные правки хранятся отдельно в `settings\user.json` и не теряются при обновлении проекта.

## Если что-то не работает

[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) — частые случаи: не поднимается туннель,
не открывается сайт, конфликт с другим обходом, троттлинг прокси.

## Ограничения

- Windows 10/11, PowerShell 5.1, права администратора для TUN и DPI.
- Публичные бесплатные прокси живут недолго: раз в 1–3 дня нужен `refresh`.
- Скорость через публичный прокси — единицы мегабит; это цена бесплатного пула.
- Один обход на машину: FFTI и сторонние desync-движки одновременно не работают.
