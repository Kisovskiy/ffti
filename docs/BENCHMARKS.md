# Замеры

Методика: `ffti.bat test` поднимает локальные порты (без перехвата всей системы), затем для
каждого адреса делает два запроса — напрямую и через FFTI — и печатает код ответа и время.

Дата: 24.11.2026. Пул: 3 SOCKS5-прокси (публичные, бесплатные). Канал: 100 Мбит/с, Хабаровск.

| Адрес | Маршрут | Напрямую | Через FFTI |
|---|---|---|---|
| ya.ru | напрямую | 302 / 452 мс | 302 / 481 мс |
| vk.com | напрямую | 302 / 472 мс | 302 / 450 мс |
| mail.ru | напрямую | 302 / 1278 мс | 302 / 728 мс |
| roblox.com | напрямую | 308 / 1774 мс | 308 / 1001 мс |
| discord.com | через туннель | 200 / 718 мс | 200 / 1019 мс |
| chatgpt.com | через туннель | 403 / 1106 мс (блок) | 200 / 1460 мс |
| spotify.com | через туннель | 301 / 788 мс | 301 / 714 мс |
| instagram.com | через туннель | нет ответа (блок) | 301 / 948 мс |

Как читать:

- Российские сайты и Roblox отвечают одинаково с обходом и без: их маршрут не меняется.
- Заблокированное напрямую не открывается (403, обрыв), через FFTI — открывается.
- Разница в 200–350 мс на заблокированных — это публичный прокси, а не обход.

## Откуда берётся скорость

| Решение | Что даёт |
|---|---|
| только домены/IP из списков идут в туннель | тоннель не трогает банки, игры, CDN и госуслуги |
| российские подсети исключены на уровне адаптера | этот трафик вообще не заходит в обход |
| игровые подсети закреплены за прямым маршрутом | пинг в играх и Roblox не меняется |
| выбор прокси по замеру, а не первый из списка | минус секунды на «мёртвых» прокси |
| DPI вместо туннеля для YouTube и Google | видео идёт на скорости канала |

## Как повторить

```
ffti.bat test
ffti.bat test ya.ru discord.com roblox.com
```

Результат складывается в `logs\test-<дата>.json`.
